# Taylor's Power Law Decomposition — Analysis Code

**Shannon T. Wong (2026)**

Code repository for:  
*"A Mechanistic Decomposition of Taylor's Power Law Reveals a Scalable Predictor of Local Population Extinction Risk"*  

---

## Overview

This repository contains the complete analysis pipeline used to produce all results in the paper. The code reproduces:

- **Theorem 2 validation** — fitted *c*₂ ≈ σ²_L across 521 BioTIME studies (Spearman *r* = 0.53 in high-dynamic-range studies)
- **Theorem 4 validation** — σ²_L / σ²_SAD < 1 in 93.3% of studies (median 0.516)
- **c₁ life-history validation** — Kruskal-Wallis *H* = 38.77, *p* < 0.0001 across 15 taxonomic realms
- **Local extinction analysis** — 20.1% vs 25.1% extinction rate (Mann-Whitney *p* = 0.0001; *n* = 3,125 species-study pairs, 706 extinctions), robust across 3 definitions and 20 jackknife replicates
- **IUCN conservation pre-screening** — Kruskal-Wallis *H* = 22.36, *p* = 1.7 × 10⁻⁴ across 6,779 matched species
- **Gillespie simulations** — numerical validation of Theorems 2 and 3 (no data required)

## Running the analysis

Scripts should be run in order. Scripts 01–03 require BioTIME data.
Script 04 (Gillespie simulations) requires no data.

```bash
# Simulations only (no data required, ~5 minutes)
python analysis/04_gillespie_simulations.py

# Full pipeline (requires BioTIME, ~40–60 minutes on modern hardware)
python analysis/01_core_analysis.py
python analysis/02_local_extinction.py

# IUCN analysis (requires API token, runs overnight for full dataset)
IUCN_TOKEN=your_token_here python analysis/03_iucn_analysis.py
```

All outputs are written to `outputs/`.

## Methods notes

**Two-term fit.** Each study is fitted as Var[N] = *c*₁M + *c*₂M² via NNLS on Var/M = *c*₁ + *c*₂M, using the single-year snapshot with the most sites. Studies with fewer than 10 sites or 12 species are excluded.

**σ²_L estimation.** Computed from the same single-year snapshot as the two-term fit (v4 method), avoiding the ~2× temporal compression bias of the time-averaged v3 method. Cross-validated via 50/50 species split.

**Local extinction definition.** Species present in the first third of a study's time series, absent from the final third. Three definitions tested (Table 1); all pre-specified before execution.

**Abundance control.** σ²_L residualised against mean abundance via OLS (log-log, slope = 0.274) to remove the rarity confound before Mann-Whitney testing.
